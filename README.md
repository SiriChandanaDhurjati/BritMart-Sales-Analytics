# BritMart Sales Analytics — Power BI Dashboard

## Overview
3-page sales analytics dashboard for a fictional UK retail chain 
built using Power BI Desktop.

## Tech Stack
- Power BI Desktop
- DAX (12 measures including time intelligence)
- Star Schema data model (5 tables)
- Row Level Security (regional roles)

## Dataset
Synthetic UK retail data — 3,000 transactions across 
6 UK regions, 20 products, 200 customers (2021–2023)

## Pages
- Executive Summary — KPIs, trends, top 10 products
- Regional Performance — treemap, YoY by region
- Product Detail — drill-through page per product

## Key DAX Measures
- Total Sales, Total Orders, Avg Order Value
- Gross Margin %, YoY Growth %, Sales YTD
- Rolling 3M Sales, Sales Rank, Dynamic Title

## Row Level Security
Regional roles configured — North England, London & SE
